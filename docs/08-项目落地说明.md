## 这东西是干嘛的

一个跑在本机的轻量重试中继，识别 Codex 流式响应里的 `server_is_overloaded` 容量错误，在输出开始前自动重试，让任务不被打断。作者实测：71 个请求吞掉 82 次重试，用户侧 0 失败。

**诚实提醒（作者原话）**：它只压住症状，不增加服务端容量，也不解决模型降智；按效果排序，换一个账号 > 把请求变小 > 重试。

## 还没做的事（需要你点头）

`scripts/install.ps1` 会改动本机环境，我没有擅自执行：

1. 修改 `~\.codex\config.toml`（已存在，安装前会备份）
2. 写入 `HKCU\...\Run` 开机自启 + 看门狗（不需要管理员）
3. 状态与日志放在 `%USERPROFILE%\.codex-overload-fix`

要装的话，在 PowerShell 里跑：

```powershell
cd "<WORKSPACE>\codex-overload-fix"
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

只想看不改动可加 `-NoConfig`；卸载用 `scripts\uninstall.ps1`。
