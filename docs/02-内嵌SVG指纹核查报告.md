## 结论先行

1. **你说的「内嵌 csv」，社区判据里的原词是「内嵌 SVG / 内联 SVG」**——是**模型首段回复里的措辞指纹**，不是 HTML 里塞了一张 CSV 数据表。本机两个鹈鹕 HTML 的 `CSV` 字面命中都是 **0**，`split(` / `<table>` 也没有，所以「内嵌 CSV 数据」这个形态在本机不成立。
2. **11/07 23:44 那次鹈鹕生成，首段回复确实命中了「内嵌 SVG」**。原话：
   > 我会直接在当前工作目录生成一个可打开的单文件 HTML：用**内嵌 SVG** 画出鹈鹕、自行车和场景，并加入车轮、脚蹬、翅膀、身体起伏等动画。完成后我会在本地做一次结构检查，确保双击即可运行。

   按社区判据，这是**约 90% 疑似被路由到 GPT-4o** 的信号。
3. **但严格判定是「混合信号」，不是铁证**：
   - 降智侧命中「内嵌 SVG」；
   - 同一句里又有「脚蹬」，final answer 里有「云朵和海边背景动态效果」（≈「背景移动」），属满血侧；
   - 社区称**基本 100%** 的强判据「循环 / 循环骑行 / 连续循环」**一次都没出现**；
   - 调用过程 ~7 分钟、带浏览器预览与静态检查、后续还有第二轮改图，成品 15900 字节 / 416 行 / 26 条 `path` / 有 `<script>` 动画控制——**完全不像 4o 典型的「秒出 + 几个静态歪圆圈方块」**。
4. **这是 11/07–11/08 排查以来第一条「行为层」线索**。这次生成正好落在之前查明的 `23:44–00:23 请求侧 gpt-6-astra xhigh` 时段：**客户端声明 astra xhigh，输出措辞却是社区标记的 4o 特征**。它提高了「那次可能没跑满血 astra」的先验概率。
5. **证据等级：强辅助，不是硬证据。** 社区自己写明「内嵌 SVG」准确率不是 100%（「确实有大佬出现了该关键词，但是没有被路由」）。要坐实仍然只有上游 `response.model` / `openai-model` / `x-openai-model` / `engine_ids`。这条不能替代抓包，但比「画得像不像」硬得多，而且**零成本、可复跑**。
6. **策略连带修正**：社区原帖另有两条与你的情况直接相关的结论——「降智跟 IP 大概率没有任何关系」「单个 IP 肯定不是主要因素」。这**进一步支持**上一版清单里「别往洗号 / 换 IP 上使劲」的判断。
